# 豆瓣 Top 250 电影爬虫

使用 Python、Requests 和 Beautiful Soup 抓取豆瓣电影 Top 250 榜单的第 1—10 页，提取电影名称、评分、引言和详情页链接，将结果保存为 UTF-8 编码的 JSON 文件。

## 项目功能

- **自动翻页**：每页 25 部电影，依次请求第 1—10 页；正常返回完整榜单时获得 250 条记录。
- **独立处理每个字段**：字段缺失、内容为空或格式解析失败时保存为 `null`，保留同一条记录中其他有效字段。
- **评分与链接校验**：评分必须是 0—10 范围内的有限数字；详情链接必须指向豆瓣电影的 `/subject/数字/` 页面，相对链接会自动补全。
- **按详情链接去重**：过滤重复链接；详情链接缺失的电影记录仍保留。
- **请求异常处理**：连接超时、HTTP 错误或电影列表无法识别时，记录失败页并继续处理下一页。
- **控制请求间隔**：使用 `requests.Session` 复用连接，相邻页面请求间隔为 2 秒。
- **逐页保存**：每页完成后写入临时文件，再替换正式 JSON；按 `Ctrl+C` 中断时保存已抓取的数据。
- **完整性提示**：检查返回页码、每页条数和总记录数；未完成 250 条时输出提示，不添加空记录凑数。

## 安装和运行

### 1. 准备环境

安装 Python 3.12，下载或克隆本项目，然后在包含 `douban_top250.py` 的目录中打开终端。

确认 Python 可用：

```bash
python --version
```

Windows 中如果 `python` 命令不可用，可以尝试将以下命令中的 `python` 替换为 `py`；macOS / Linux 通常使用 `python3`。

### 2. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 3. 运行爬虫

```bash
python douban_top250.py
```

脚本会在终端显示正在抓取的页码，并将数据写入**运行命令时所在目录**下的 `douban_top250.json`。每次运行都会从第 1 页重新抓取并覆盖同名文件；逐页保存不等于断点续爬。

成功抓取完整榜单时，日志最后会显示已保存 250 条记录。若出现请求失败或数据不完整的提示，应结合失败页码检查结果；文件生成并不代表一定抓取到了 250 条。

## 翻页逻辑

请求地址为 `https://movie.douban.com/top250`，查询参数中的 `start` 表示跳过的电影条数：

```python
for page in range(1, 11):
    start = (page - 1) * 25
    params = {"start": start, "filter": ""}
```

| 页码 | `start` | 正常对应的榜单位置 |
| --- | --- | --- |
| 1 | 0 | 1—25 |
| 2 | 25 | 26—50 |
| 3 | 50 | 51—75 |
| 4 | 75 | 76—100 |
| 5 | 100 | 101—125 |
| 6 | 125 | 126—150 |
| 7 | 150 | 151—175 |
| 8 | 175 | 176—200 |
| 9 | 200 | 201—225 |
| 10 | 225 | 226—250 |

## JSON 数据格式

顶层是电影记录数组，每条记录都保留以下四个字段：

| 字段 | 含义 | 类型 |
| --- | --- | --- |
| `name` | 页面中第一个电影标题，通常为中文名称 | 字符串或 `null` |
| `rating` | 豆瓣评分 | 数字或 `null` |
| `quote` | 榜单上的简短引言 | 字符串或 `null` |
| `url` | 电影详情页完整链接 | 字符串或 `null` |

以下是格式示例，其中 `null` 用于演示引言缺失的情况，不是实际电影数据：

```json
[
  {
    "name": "示例电影",
    "rating": 9.0,
    "quote": null,
    "url": "https://movie.douban.com/subject/123456/"
  }
]
```

程序内部使用 Python 的 `None` 表示缺失值，`json.dump()` 会将其转换为 JSON 的小写 `null`，不是字符串 `"NULL"`。保存时使用 `ensure_ascii=False`，中文可直接阅读。

## 可调整参数

配置位于 `douban_top250.py` 顶部：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `PAGE_COUNT` | `10` | 需要抓取的页数；Top 250 榜单共 10 页 |
| `PAGE_SIZE` | `25` | 与网站每页条数一致，用于计算 `start` |
| `REQUEST_INTERVAL` | `2` | 相邻页面请求间隔，单位为秒 |
| `OUTPUT_FILE` | `douban_top250.json` | 输出路径；自定义目录需事先存在 |

HTTP 请求中的 `timeout=(10, 20)` 分别设置连接超时和读取超时。

## 常见问题

- **提示缺少 `requests` 或 `bs4`**：使用运行脚本的同一个 Python 执行 `python -m pip install -r requirements.txt`。
- **引言为 `null`**：可能是页面没有提供引言，也可能是该字段解析失败；其他字段和后续电影继续处理。
- **遇到 403、429 或验证页面**：脚本会输出警告并继续处理后续页，结果可能不足 250 条；可稍后再运行或增大请求间隔。脚本不实现验证码处理或代理轮换。
- **所有页面均失败**：输出可能是空数组 `[]`，应检查终端中的失败原因。
- **重新运行覆盖旧数据**：需要保留旧快照时，先备份 JSON，或修改 `OUTPUT_FILE`。
- **无法保存 JSON**：检查运行目录是否可写，以及磁盘空间是否充足。
